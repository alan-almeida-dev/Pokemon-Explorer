# Pokémon Explorer

Aplicação web desenvolvida com HTML, CSS e JavaScript que utiliza a PokeAPI para consultar e apresentar informações sobre Pokémon.

O projeto permite pesquisar Pokémon, filtrar resultados e gerenciar uma lista de favoritos.

## Funcionalidades

- Listagem de Pokémon
- Pesquisa por nome
- Pesquisa por ID
- Filtro dos resultados
- Adição de Pokémon aos favoritos
- Remoção de Pokémon dos favoritos
- Interface responsiva
- Consumo da PokeAPI

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Bootstrap
- PokeAPI

## Como executar

Clone o repositório:

```bash
git clone https://github.com/alan-almeida-dev/Pokemon-Explorer.git
```

Entre no diretório:

```bash
cd Pokemon-Explorer
```

Depois, abra o arquivo `index.html` no navegador.

## Consumo de API

A aplicação utiliza a PokeAPI para obter os dados dos Pokémon e apresentar as informações na interface.

## Objetivo

O projeto foi desenvolvido como prática de desenvolvimento frontend, consumo de APIs e manipulação de dados utilizando JavaScript.
